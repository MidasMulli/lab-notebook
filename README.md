# Lab notebook

A lab notebook about learning and inference on BrainChip's AKD1500 and Apple's Neural Engine, alongside camera-based MechDog experiments. Entries separate host work from chip work.

Read it at **https://midasmulli.github.io/lab-notebook/**.

Each entry gives results, controls, limits and links to available evidence. Some historical compiled artifacts are not shipped; such limits are stated. Internal AI-assisted checking is not external replication or formal peer review. New results are announced on X at [@NickLo641579](https://x.com/NickLo641579).

Plain static HTML, no build step. `ENTRY_TEMPLATE.md` describes how an entry is written.
